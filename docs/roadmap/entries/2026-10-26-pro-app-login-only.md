- 🟢 **L’app Pro connecte les salons, elle ne les inscrit plus : la réponse au refus d’Apple (3.1.1) — iOS et Android (2026-10-26).** ([pro-app-login-only.md](../../design/pro-app-login-only.md) ; [BACKLOG](../../BACKLOG.md) B0.11, décisions 38–43) PR #NNN.
  - **Avant** : Apple a refusé la 0.0.1 (587) : « Remove the account registration features for business and organizations ». L’app avait le formulaire « Inscription Pro » (« Créer un compte », « S’inscrire ») et « Ajouter un salon » ; nos notes de revue invitaient même le relecteur à créer un compte.
  - **Ce qui change** : les deux quittent l’app, avec leurs méthodes — le web les garde (`/pro/inscription`, `/pro/salons/nouveau`) ; les invitations restent ; « S’inscrire sur myweli.com » ouvre l’inscription web dans le navigateur (choix du propriétaire, risque assumé) ; une connexion sans compte dit « Aucun compte MyWeli Pro n’est associé à cette adresse. Si votre salon vous a invité… ». Recherché avant de trancher : la politique Google Play, Planity Pro, Booksy Biz, les « reader apps ». Les notes de revue et la réponse au Resolution Center disent la chose franchement.
  - **À suivre** : les vérifications sur l’iPhone (B0.2), puis le renvoi d’un nouveau build de la 0.0.1 (B0.3) ; « Prendre rendez-vous » vers l’app MyWeli quand elle sera publiée.
