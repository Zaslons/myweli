- 🟢 **La CI ne télécharge plus Postgres : les deux jobs backend démarrent celui du runner (CI, 2026-10-15).** **Le défaut, observé** : les jobs « Backend — Analyze & Test » et « Backend — boot smoke + funnel e2e » tiraient une image `postgres:16` comme conteneur de service. Docker Hub les avait fait échouer le 2026-10-09 (#558, #559) ; le miroir ECR Public adopté alors échouait à son tour — « toomanyrequests: Data limit exceeded », sept fois le 2026-10-15, deux fois de suite sur #611 — avant qu'une seule ligne de code ne tourne : un téléchargement anonyme est limité par adresse IP, et les runners de GitHub partagent les leurs. Chaque échec bloquait une fusion jusqu'à une relance manuelle. **Le correctif** : `.github/scripts/start-postgres.sh` démarre le PostgreSQL que l'image Ubuntu du runner installe déjà (arrêté par défaut), crée la base du job, pose le mot de passe que `DATABASE_URL` attend, et prouve la connexion TCP avant de rendre la main — plus aucun téléchargement. La production est Cloud SQL PostgreSQL 16 : le script **échoue** si le runner passe à une autre version majeure, au lieu de tester en silence contre elle.
