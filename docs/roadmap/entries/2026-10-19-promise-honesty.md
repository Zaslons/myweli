- 🟡 **Ce que l'app promet = ce qu'elle fait : plus de rappels « WhatsApp/SMS », plus d'acompte « payé en ligne », plus de « modifie » dans l'invite du salon ; fusionné (#639) : le web en ligne ; l'app part avec 0.0.2 (web + app Pro + docs, 2026-10-19).** ([promise-honesty-sweep.md](../../design/promise-honesty-sweep.md)) Trouvés par la revue d'honnêteté de la vidéo promo, **chacun relu sur le vrai chemin de code** avant toute correction. **(1)** La carte d'offre Pro du web vendait « Rappels automatiques WhatsApp/SMS » : la production tourne en `MESSAGING_PROVIDER=disabled` jusqu'à l'immatriculation — mais les rappels 24 h / 2 h **existent**, par notification de l'app MyWeli (push + fil), pour un client qui a réservé avec un compte ; un client saisi par le salon n'en reçoit aucun. **(2)** « Acompte payé en ligne » (écran Acompte, app Pro) : l'acompte part par Mobile Money sur le numéro du salon, prouvé par capture — jamais en ligne. **(3)** L'invite push de l'Accueil Pro promettait de prévenir quand un client « modifie » : `SalonEvent` n'a que réservation, annulation, justificatif d'acompte ; un « Reporter » du client ne prévient que le client. **Le balayage en a trouvé trois de plus** : la tuile « Confirmations WhatsApp » de l'accueil web, « WhatsApp/SMS reminders » dans `llms.txt`, et le bandeau « notifications désactivées » de l'app Pro qui promettait au salon « vos rappels et confirmations » (le texte du client). **Texte validé mot pour mot par le propriétaire** (T1–T6). **Les fiches de store sont justes** (relues : Play ×2, App Store Pro) — aucune à modifier ; mais le build Pro 587 en TestFlight porte encore l'ancien texte, corrigé au prochain build. **Gardes, vues rouges sur `main` avant la correction** : une épingle de source par surface (app : `lib/` + les sections fiche des deux docs de store ; web : `app/`, `components/`, `lib/`, `llms.txt`) sur trois familles de phrases, **chacune adossée à un fait que le test relit** — `MESSAGING_PROVIDER` dans `infra/gcp/service.yaml`, l'`enum SalonEvent` du serveur — si le fait change, le test échoue en demandant de re-décider au lieu de se relâcher en silence ; plus un test de widget pour le bandeau Pro et une ligne d'offre sans canal de messagerie. Le dépouilleur de commentaires Dart passe dans `test/support/dart_source.dart` (partagé, ses auto-tests inchangés). **Vérifié ici** : `flutter analyze` 0, format propre, 122 tests app ciblés verts ; web : typecheck, lint, 1 577 tests unitaires verts. **Suite proposée** : prévenir le salon quand un client reporte (serveur) — après quoi l'invite pourra redire « modifie », et l'épingle le signalera.
