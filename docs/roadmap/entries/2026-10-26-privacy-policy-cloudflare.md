- 🟢 **La politique de confidentialité dit ce que le passage par Cloudflare a changé : votre adresse IP arrive chez Cloudflare, Google Cloud ne voit plus que la sienne (site, 2026-10-26).** ([BACKLOG](../../BACKLOG.md) B0.4, décision 3 ; App Store 5.1.1(i)) PR #709.
  - **Avant** : la page disait que Google Cloud enregistre « votre adresse IP » — vrai jusqu'au 7 octobre, faux depuis que `api.myweli.com` passe par Cloudflare (mesuré : 60 journaux sur 60 portent une adresse de Cloudflare). Cloudflare n'était nommé que pour les fichiers ; la phrase « protection au moins équivalente » qu'Apple demande manquait ; le chemin d'export de l'app Pro était faux ; et la date de la correction du script de Google renvoyait à la date de la page, fausse depuis le 22 août.
  - **Ce qui change** : chaque appel à l'API passe par Cloudflare, qui reçoit l'adresse IP ; Google Cloud ne voit que celle de Cloudflare ; le limiteur de connexions n'en garde qu'une empreinte, effacée sous deux jours ; Cloudflare parmi les prestataires, avec ses deux rôles ; la protection équivalente ; « Profil → Mes données » dans MyWeli Pro ; « le 21 août 2026 » ; quatre mots qui se collaient (« sontdésactivées »…) séparés. Les mentions légales nomment le second rôle de Cloudflare. Date des documents : 26 octobre 2026.
