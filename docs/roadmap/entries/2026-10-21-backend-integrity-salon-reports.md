- 🟢 **Le salon signale un avis (serveur + web + app, 2026-10-21 — déployé le 2026-10-22).** ([backend-integrity-batch6.md](../../design/backend-integrity-batch6.md) §12) Le lot 6 du [BACKLOG](../../BACKLOG.md), PR C (B6.6 ; décision 20). **Avant** : l'écran « Avis » du Pro n'avait aucun moyen de signaler un avis — App Store 1.2 en attend un pour tout contenu d'utilisateur. **Ce qui change** : `POST /me/provider/reviews/{id}/report`, pour le Propriétaire et le Gérant (`profile.manage`), et seulement pour un avis de leur salon (sinon 404). Le signalement va dans la même file que celui d'un client, marquée « Signalé par le salon » dans la console d'administration. Il est idempotent par avis et par salon. La migration 0041 ajoute `review_reports.reporter_kind`. « Signaler » arrive sur l'écran « Avis » du web Pro et de l'app Pro, avec le formulaire et les mots du client, et le style discret du client. **Gardes** : les tests rouges d'abord ; 21 mutations vues rouges, dont trois qui ont d'abord survécu et ont chacune demandé un test ; les quatre suites entières (serveur avec Postgres, web, app, e2e). **À suivre** : PR D (Apple), puis un déploiement — demandé avant.
