- 🟡 **Les rapports CSP du site portent leur environnement Sentry (web · observabilité, 2026-10-28 — BACKLOG B0.7).** Le navigateur envoie lui-même chaque rapport de violation CSP à l'adresse `report-uri` ; aucun SDK n'y joint d'environnement, donc ces rapports arrivaient sans. L'alerte par défaut du web (`757125`) ne pouvait pas surveiller la seule `production` sans les rendre muets — `MYWELI-WEB-9`, un script `connect.facebook.net` bloqué sur myweli.com le 2026-10-21, en est un. Décision du propriétaire : filtrer, et marquer les rapports. `sentryReportUri` ajoute `sentry_environment`, nommé par la même expression que les trois `sentry.*.config.ts` (`NEXT_PUBLIC_SENTRY_ENV ?? 'development'`) ; un test lit l'en-tête construit par la config exportée et épingle les quatre écritures ensemble (cinq mutations vues rouges). L'alerte du backend (`757123`) filtre déjà `prod`, relue par l'API. **Reste :** fusionner (= redéployer myweli.com), relire l'en-tête déployé, puis filtrer `757125` sur `production`. Détail : [observability-error-reporting.md](../../design/observability-error-reporting.md) §8.1.1.
