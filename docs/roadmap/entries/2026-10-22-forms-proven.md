- 🟡 **Chaque formulaire dit sa faute sous le champ : la feuille des tags sur `FieldErrors`, et un code refusé dit sous le code, comme sur le web (app, 2026-10-22).** ([hygiene-batch9.md](../../design/hygiene-batch9.md) §11) Le lot 9 du [BACKLOG](../../BACKLOG.md), PR C (B9.7).
  - **Avant** : dans la feuille des tags, la faute s'effaçait à la première frappe ; la onzième puce ne faisait rien, sans un mot ; un enregistrement refusé laissait la feuille ouverte, muette ; à dix tags la feuille débordait. Les trois connexions par e-mail disaient « Code incorrect. » sous le formulaire, et « Numéro ou code invalide. » sur une étape sans numéro. Cinq formulaires n'avaient aucun test « sous le champ ».
  - **Ce qui change** : la feuille redemande sa règle, dit la limite pour une puce aussi, dit l'échec dans la feuille, et défile. Une table (`sign_in_refusal.dart`, la copie de celle du web) met chaque refus sous son champ — code, e-mail — et le reste au formulaire. 15 des 17 écrans ont leur test ; les deux derniers attendent le SMS. Part avec 0.0.2.
