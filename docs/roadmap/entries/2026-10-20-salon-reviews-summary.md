- 🟡 **« Avis » : la carte compte le salon entier — le serveur envoie la note, le nombre et la répartition avec chaque page ; fusionné (#658) ; le serveur et le web en ligne ; l'app part avec 0.0.2 (backend + web + app, 2026-10-20).** ([salon-reviews-summary.md](../../design/salon-reviews-summary.md)) **Le constat** (audit de parité §4) : le web faisait la moyenne des avis chargés (50 par page) à côté du total du serveur ; l'app celle des 50 premiers, en les appelant « N avis » — faux au-delà de 50, sans le dire. **Ce qui change** (décision du propriétaire : le résumé du serveur, web et app) : `GET /me/provider/reviews` envoie `summary` — la moyenne à une décimale (la note publique du salon), le nombre et la répartition 5 → 1, sur tous les avis visibles ; le web et l'app dessinent la carte avec, et retombent sur la page si un serveur ancien ne l'envoie pas. **Gardes** : rouges d'abord sur les trois couches, 7 mutations vues rouges (une survivante, attrapée par un test d'écran ajouté) ; serveur 1 757 + Postgres, web e2e 98, app 1 844.
