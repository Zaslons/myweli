La page n’y est pour rien. L’indication s’affiche un effet React après la page, par conception (le rendu serveur et le premier rendu du navigateur doivent être identiques). Sur 15 essais : rendu ralenti de 4 ms + 2 ms de pause → 0/15 trouvé ; l’un ou l’autre seul → 14 à 15/15 ; les deux, avec l’horloge du Scheduler figée (il ne peut plus rendre la main) → 15/15. Le vrai fichier, non modifié, sous les deux : 3/3 le même échec, même ligne `172:28`, même DOM que la CI. Ni le fuseau (aucun test n’y touche ; la CI affichait bien les heures de Libreville), ni l’ordre des fichiers entre workers Vitest.
